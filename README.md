# 打工人桌面放松工具 · Relax Desktop Tool

一个**单文件 HTML 桌面小工具**，挂在屏幕右下角，帮打工人安全地发泄、休息、闲聊。
纯前端、无后端、无安装、双击即用，老 Mac 也能流畅跑。

## 功能

- **💥 狂怒模式**：点一下，角色由小长大、金光炸裂，满屏「桌面文件」成波轰碎（拳皇式电影特效：白闪 + 屏幕震动 + 径向冲击波 + 暗角黑边），约 5 秒恢复平静。
- **🌙 休息模式**：角色陪你，屏幕提示「休息中…」，可缓解绷紧状态。
- **🌿 自由模式**：松弛状态，角色带呼吸动画，陪你发会儿呆。
- **💬 Distill 聊天**：面板内嵌 [Distill](https://distill.uichain.org)，点开即和「无数人」（中本聪、马斯克、前任、老板……）对话。
- **📷 换角色**：可换成**自己的照片**当主人翁（存在浏览器本地，下次自动记住）。
- **🔊 音效**：开关砸击声（老 Mac 没声音可关）。
- 快捷键：`1` 狂怒 / `2` 休息 / `3` 自由 / `H` 收起面板。

## 隐私与安全（重要）

- **狂怒模式是纯视觉特效**：浏览器出于安全**读不到你真实的桌面文件**，显示的是常见文件名铺满屏来制造「这就是我桌面」的代入感。**不会读取、不会删除你任何真实文件**。
- 聊天仅内嵌公开站点 Distill，不收集你的对话。
- 换角色照片仅保存在你自己的浏览器 `localStorage`，不上传任何服务器。
- 本仓库**不含任何个人数据、密钥或凭据**；角色图 `assets/hero_cut.png` 为 AI 生成的演示占位形象，可随时替换。

## 使用

1. 把本仓库下下来（或确保 `relax_tool_v5.html` 与 `assets/` 文件夹在同一目录）。
2. 双击 `relax_tool_v5.html` 用浏览器打开（Chrome / Safari / Edge 均可）。
3. 点右下角的黑金小圆点 ⚔ 唤醒面板，选择模式即可。

> 提示：`assets/hero_cut.png` 与 HTML 同目录时显示真实抠图角色；若图片缺失，自动用 🗡️ 兜底，不影响使用。
